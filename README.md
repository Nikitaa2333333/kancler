# Канцлер — сайт бухгалтерского и управленческого учёта для строительных компаний

Astro 5, чистый CSS на токенах. Правила и состояние работы — `CLAUDE.md`, ТЗ — `docs/`.

- Локально: `npm install`, `npm run dev` → http://127.0.0.1:4340/
- Тестовая выкладка: GitHub Pages, автоматически из `main` →
  https://nikitaa2333333.github.io/kancler/
- Боевой хостинг: SprintHost (позже). Префикс пути задаётся `PUBLIC_BASE`, ссылки в коде —
  через `u()` из `src/lib/url.ts`.
