# Вертикальный ритм и сетка — как устроен пульт

Все расстояния управляются переменными в `src/styles/tokens.css` (блок «ВЕРТИКАЛЬНЫЙ
РИТМ И СЕТКА»). Значения сняты с референса Avenir (секции 120px, гаттер 16px, поле 32px)
и подогнаны под вьюпорт ~1280 CSS-px через `clamp()`.

| Ручка | Что делает | Обычный диапазон |
|---|---|---|
| `--section-gap` | отступ секции сверху и снизу (штатный) | 48–140px |
| `--section-gap-tight` | поджатый вариант (`.sec--tight`) | 32–80px |
| `--section-gap-roomy` | просторный вариант (`.sec--roomy`) | 64–160px |
| `--head-gap` | заголовок секции → её контент | 24–64px |
| `--card-gap` | зазор между карточками | 12–24px |
| `--page-max` | ширина контента | 1280–1600px |
| `--gutter` | боковые поля страницы | 16–40px |
| `--hero-frame` | белое поле вокруг hero (рамка) | 4–12px |

## Правила

1. Секции читают ТОЛЬКО переменные: `.sec { padding-block: var(--section-gap) }`.
   Своих цифр в компонентах нет.
2. Резина — через `clamp(мобила, vw, десктоп)` прямо в значении переменной.
3. Точечные отклонения — модификаторами (`.sec--tight`, `.sec--roomy`,
   `.sec--flush-top`), а не правкой общей переменной.
4. Горизонтальные поля — контейнер `.wrap` (`--gutter`, `--page-max`).
5. Просят «поменять расстояния» — правим переменную, а не отдельные секции.

## Ловушки

- **Дыра между секциями = удвоенный `--section-gap`** (низ верхней + верх нижней).
  Нужен разрыв 160px — ставим 80px.
- **Расширение `--page-max` разносит вёрстку:** поля формы растягиваются простынёй,
  картинка раздувается по высоте текста. Лечится на самом элементе (`max-width` +
  `margin-inline:auto`, `aspect-ratio`, `minmax(0, 1fr)`), а не сеткой. После заметного
  изменения ширины смотреть блоки с картинками и формой.
- **Мера строки** — токены `--measure-*` (в `ch`), ставятся на сам текстовый элемент.

## Мой экран

Windows-масштаб 150 %: монитор 1920px даёт странице ~1280 CSS-px. Правки выше этой
ширины физически не увидеть — сначала прикидывать, попадает ли значение в вьюпорт.
