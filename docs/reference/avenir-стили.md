# Avenir (референс) — стили, снятые с живого сайта

Источник: https://avenir-template.webflow.io/ (Webflow-шаблон Avenir, BYQ Studio).
Снято 22.10.2026 с живой страницы: значения из `:root`, вычисленные стили ключевых
элементов, исходный CSS (`avenir-code/avenir.webflow.shared.css`, 765 КБ) и HTML
(`avenir-code/index.html`). Скриншоты всей страницы — `avenir-screens/01…16`.

**Что можно брать, чего нельзя.** Значения (цвета, кегли, сетка, радиусы, отступы,
структуру секций) берём как основу. Не берём: логотип и слово Avenir, фотографии и видео
шаблона, шрифт Raveo Display (им набран только логотип-вордмарка), готовую разметку и
CSS целиком — это платный шаблон, наш сайт собирается заново на Astro. Код Webflow лежит
здесь только как справка, в сборку не попадает.

Скриншоты 01–08 сняты в 1500×756, 09–16 — в 1050 по ширине (масштаб 0.7, окно стало
ниже). Для сверки на готовом сайте снимать при ширине 1500 и сравнивать по секциям.

## Что в референсе противоречит нашим правилам (глобальный CLAUDE.md)

Копируем стиль «прямо», но эти места правим при переносе, иначе нарушим правила
пользователя. Проговариваем, а не молча подменяем:

1. **Капс.** Метки секций (`OUR EXPERTISE`, `TRUSTED IMPACT`, `MEET AVENIR`, `NEWS & INSIGHTS`),
   копирайт и имя в цитате набраны прописными моноширинным шрифтом с трекингом 0.75px.
   Правило: капс и разрядка запрещены. Делаем метки строчными, тем же мелким кеглем и
   весом 500 (по правилу «кегль плюс semibold читается как метка»); моно-шрифт — только
   если найдём кириллический.
2. **Приглушённый текст.** Основной текст абзаца `rgba(11,46,60,.88)`, подписи 64 %,
   плейсхолдер 48 %. Правило: никакой прозрачности на тексте. Берём сплошной `#0b2e3c`;
   иерархию строим кеглем и шрифтом. Исключение — плейсхолдеры полей (оставляем, проговорить).
3. **Светлый текст на фото** (hero) — оставляем чисто белым `#fff` вместо `#f7f6f5`.
4. **Вес.** В референсе жирности внутри фраз нет, есть только Inter Tight 500 на кнопках
   и метках — это служебный интерфейс, разрешено.
5. **Мера строки.** Манифест 928px при 52px — около 22–28 знаков в строке, это заголовок,
   ок. Абзацы в референсе узкие (463px при 16px ≈ 60 знаков) — укладываются в нашу меру.
6. **Масштаб.** У пользователя Windows 150 %, реальный вьюпорт ~1280 CSS-px. Размеры
   h1/h2 52–64px и контейнер 1440px там не раскроются — подбирать под 1280.
