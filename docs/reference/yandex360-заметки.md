# Референс: Яндекс 360 (https://360.yandex.ru/), снято 03.11.2026

Пользователь: «нравится, как там плашки выглядят, и иллюстрации, и ноут-, и мобильная версия».
Скриншоты — `docs/reference/yandex360/` (`d-*` — ноутбук 1440, `m-*` — телефон 390).
Цифры сняты с отрисованной страницы (computed style).

## Плашки (карточки)

| | Ноутбук 1440 | Телефон 390 |
|---|---|---|
| Скругление | 40 px | 32 px |
| Внутреннее поле | 40 px | 32 px |
| Зазор между плашками | ≈ 12–16 px | ≈ 8 px |
| Отступ плашек от края экрана | ≈ 24 px | 12 px |
| Фон основной | `#e9edfc` (холодный светло-сиреневый голубой) | тот же |
| Акцентная плашка | тёмная `#34343c` с белым текстом; яркая оранжевая | — |

- Сетка услуг на ноутбуке: 3 крупные плашки в верхнем ряду + 4 поменьше во втором — разный
  размер, «журнальная» раскладка. На телефоне — по одной в ряд, все одной высоты.
- В плашке: заголовок, под ним серое описание, круглая белая кнопка-стрелка `→`.
  3D-иллюстрация — в правом нижнем углу, крупно, **срезана краем плашки** (выходит за угол),
  за ней цветной круг-подложка.
- «Дополнительные преимущества» — бенто-сетка: одна высокая плашка слева (тёмная, с большой
  3D-картинкой) + 2×2 справа, одна из них яркая.
- «Технологии защиты» — горизонтальная лента тёмных плашек со стрелкой справа.
- Частые вопросы — каждый вопрос отдельной светло-серой плашкой (`r≈20`), плюс в белом
  квадратике справа.
- Тарифы — белые плашки на синем полотне с крупной 3D-картинкой в углу.

## Типографика

- Заголовки секций: 48/48 px (телефон 28/28), вес 500, цвет `#34343c` (не чёрный —
  графит), по центру, над ним мелкий надзаголовок капсом (у нас капс и надзаголовки
  запрещены — не берём).
- Заголовок плашки: 24/26 px (телефон 16/20), вес 500, широкий гротеск YS Text Wide.
- Описание: 18/22 px (телефон 16/20), серый `#6b6c77`.

## Иллюстрации

- 3D: мягкий матовый пластик + матовое стекло, крупные, без мелких деталей, один-два цвета
  на предмет, мягкая тень. Часто «вылезают» за край плашки.
- Первый экран: композиция из полупрозрачных стеклянных дисков и 3D-объектов вокруг заголовка.

## Что берём для «Канцлера»

1. Плашки: скругление 32–40 px, поле 32–40 px, на телефоне — 12 px от края экрана.
2. 3D-картинка в правом нижнем углу плашки, крупно, срезана краем плашки (пользователь
   выбрал 3D 03.11.2026, проба — `/proba-illyustracii/`).
3. Круглая кнопка-стрелка в плашке услуги вместо длинной кнопки «Подробнее».
4. Бенто-раскладка для «Почему выбирают нас»: одна крупная + несколько поменьше.
5. Частые вопросы — каждый вопрос отдельной плашкой.

Не берём: капс-надзаголовки, центровку длинных заголовков, оранжевый (у нас синяя палитра).
