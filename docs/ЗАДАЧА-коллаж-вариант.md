# Задача: второй вариант главной — «коллажный» (отдельная страница)

Открыта 23.10.2026. Делать в **отдельном чате**. Основная главная (`/`) — строгий
корпоративный вариант, его не трогаем. Коллажный — новая страница, например
`/variant-collage/` (`src/pages/variant-collage.astro`), закрыта от индексации, в меню не
ссылается. Тексты — те же из `src/data/home.ts`, структура блоков та же (ТЗ не меняется),
меняется только подача.

## Идея пользователя

Редакционный коллаж, как в журнальных обложках: чёрно-белые фото с растровой точкой
(руки, документы, калькулятор, стройка), рваные края бумаги, плоские цветовые поля, сетка
миллиметровки, линия графика поверх. Совмещаем руки, бухгалтерию и строительство.
Коллаж разобрать на отдельные вырезки и **анимировать**: фото-вырезки — PNG с прозрачностью,
графика (поля, линия графика, квадраты, круг, сетка) — родной SVG; линия графика
прорисовывается, плашки выезжают, вырезки всплывают и чуть покачиваются.

**Палитра — спокойная, ничего яркого** (решение пользователя): тёмно-синий `#0b2e3c`,
приглушённый зелёный `#7f9f8a` / `#c9d8cc`, голубо-серый `#b8cdd4`, бумага `#f7f6f5`,
чёрно-белые фото. Жёлтый из первого теста — отвергнут как слишком яркий.

## Референсы

`docs/reference/collage/`:
- `collage-1…4` — стиль картинок (Pinterest: руки с документом и калькулятором на синем,
  налоговая форма над ноутбуком, город с графиком, небоскрёбы с красным полем);
- `ui-1-medium`, `ui-2-energy`, `ui-3-green-nyse` — референсы по интерфейсу/подаче
  (коллажные обложки с UI-метками, Energy Central, зелёный NYSE).

## Что уже сделано (хаб image-styler, namespace `kancler`)

- Стиль `presets/kancler/_base-collage.md` (техника, палитра, запрет любого текста —
  модель писала «ESTIMATE» на смете).
- Пресет `presets/kancler-collage-flash.json` (Flash, рефы `input/kancler/ref-collage-*.jpg`).
- Цельный коллаж для первого экрана: `output/kancler/hero-collage.png` (жёлтый — отвергнут),
  `hero-collage-v2.png` (палитра синий + зелёный) — посмотреть результат.
- Сцены отдельных вырезок на хромакее `#FF00FF`: `el-building`, `el-hand-sheet`,
  `el-hand-calc`, `el-blueprint` (`presets/kancler/scenes/`). Тестово запущена только
  `el-building` → `output/kancler/el-building.png`. Остальные — после проверки, что фон
  чисто вырезается (PIL, ключ по пурпурному, белая «наклеечная» кайма должна остаться).

Запуск одной вырезки:
```
python "$HUB/run.py" --preset kancler-collage-flash --scene el-hand-sheet \
  --refs input/kancler/ref-collage-1-hands-blue.jpg input/kancler/ref-collage-3-city-chart.jpg \
  --out "$HUB/output/kancler/el-hand-sheet.png"
```

## Поворот концепции 23.10.2026 — «брут»

Пользователь по референсам `ui-1-medium`, `ui-2-energy`, `ui-3-green-nyse`: современнее,
смелее, брутализм; шрифт без засечек; больше зелёного. Решено: **Onest** на всё,
зелёный **средней яркости, как у Medium** (`#5fae5f` + светлый `#bcd9b0`, фон-бумага
`#e8eedf`, тёмный `#0f1a12`), прямые углы, рамки 1.5px, жёсткая тень кнопок, рамки
«UI-разметки» с ярлыками (строчными). Палитра «синий + шалфей» для этого варианта снята.
Строгая главная остаётся как есть — **два варианта**.

Устройство: `src/styles/theme-brut.css` + `import '@fontsource-variable/onest'` только в
`variant-collage.astro`, `<Base theme="brut">` ставит класс на body. Тема переопределяет
токены; блоки ниже первого экрана — общие компоненты главной (их параллельно меняет
другой чат — тема на токенах это переживает, но точечные правила по селекторам
`.svc__card`, `.aud__grid li` и т. п. могут отвалиться при переименовании).
Вырезки остались ч/б — на зелёном поле читаются как у Medium.

Правки пользователя 23.10.2026 (вечер): миллиметровка — фоном всей плашки первого экрана;
рамки «UI-разметки» у заголовка и кнопки сняты; карточка «Управленческий учёт» —
светлый зелёный (насыщенный «бьёт»); «Для кого» — свой компонент `AudienceCollage.astro`
с вырезками `aud-{general,sub,finish,eng}.webp` (сцены `el-aud-*`). Генерация: с одним
референсом Flash правит сам референс, а не рисует новое; каска вышла только с третьей
попытки, когда в рефы дали удачную вырезку на пурпурном (`el-aud-sub.png`) — так и
делать для новых вырезок.
