# Иллюстрации «Канцлера» — зафиксированный стиль (03.11.2026)

Утверждено пользователем 03.11.2026 после проб (`/proba-illyustracii/`, файл Figma
«Канцлер — иллюстрации (тест стилей)», https://www.figma.com/design/RtzBQCXgFUyGa6evkfPZEq).
Эталон — картинки 1–3 «Типичных ситуаций» (`public/images/ill/sit-1..3.webp`). Любая новая
картинка делается **только по шаблону ниже**, меняется лишь блок «СЮЖЕТ».

Генерация: Figma MCP `generate_image`, модель `gpt-image-2.5-flare`, 1024×1024. Фон
вырезается скриптом (белое от краёв → прозрачное, тень полупрозрачная), результат —
`public/images/ill/<имя>.webp` 640×640.

## Правила стиля

1. **Материалы:** главный предмет — матовое полупрозрачное голубое стекло (градиент
   `#2f7fe0 → #6ab8f2`), без свечения и неона. Рядом — настоящие материалы: белая бумага
   слоями, металл ключа, белый пластик каски.
2. **Цвета:** голубое стекло, тёмно-синий `#004a85` (плотные детали), белый; один маленький
   акцент светло-песочным бежевым (бирка, закладка, ярлычок). Нет зелёного, оранжевого,
   фиолетового.
3. **Сюжет:** один главный предмет + 1–3 помощника, которые сразу объясняют смысл карточки.
   Главный предмет на каждой карточке **свой** — не повторяем (папку взяли один раз и всё).
4. **Детали крупные:** слои бумаги, ярлычки, бирки, загибы, кольца. Без мелочи, без текста,
   букв и цифр; вместо текста на бумаге — синие полоски.
5. **Не делаем:** мультяшность, «пушистость», игрушечные пропорции, пластиковый вид,
   стрелки, людей и руки, кучу одинаковых предметов («мусор»).
6. **Свет:** мягкий рассеянный студийный, мягкие тени, лёгкое плёночное зерно. Изометрия с
   небольшим наклоном, предмет занимает ~65–70 % кадра, фон чисто белый.

## Тёмные плашки (шаги «Как начинаем работу»)

Для картинок на тёмной плашке фон генерируем сразу тёмный: в конце шаблона вместо белого фона —
`NO white outline or halo around objects ... Plain solid dark navy background exactly #1c2a40,
uniform, no gradient, no vignette.` Модель даёт фон ≈ `#17253c`, его и вырезаем; цвет плашки
`--c-night` = `#17253c`. Картинки с белого фона на тёмную плашку **не ставить** — остаётся
белая кайма (03.11.2026).
