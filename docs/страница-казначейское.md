Ежемесячное казначейское сопровождение
Стоимость указана для одного муниципального или государственного контракта, по которому применяются казначейское сопровождение и/или целевое финансирование. Окончательная стоимость определяется после анализа контракта, условий авансирования, количества платежей, объема документации и состояния учета.
